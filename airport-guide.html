如何购买和使用 VPN 机场

“机场”是提供代理线路的服务商。你在机场网站购买套餐，再把线路导入手机或电脑上的客户端。

每个机场都有自己的详细使用教程。买好套餐后，打开机场后台的「使用指南」或「如何使用」，选择自己的手机或电脑系统，跟着教程一步步操作即可。下面的通用步骤可以帮你先了解整个流程。

选择一家机场

点击名称进入注册页面。

  1. 注册机场账号

    打开你选好的机场官网，点「注册」。按提示填写邮箱、设置密码；如果收到验证邮件，完成验证后再登录。

  2. 购买线路套餐

    在「套餐」「商店」或「购买服务」里，先看有效期、可用流量和包含的节点地区，再选择合适的套餐付款。回到个人中心，确认套餐已生效，并能看到到期时间或剩余流量。

  3. 按设备下载客户端，找到对应的订阅

    大多数机场都支持安卓手机和 Windows 电脑上的主流客户端。先打开机场后台的「使用指南」，选择你的系统，再从下面的官方地址下载教程推荐的那一款。

    安卓手机

    v2rayNG、Clash Meta for Android、NekoBox for Android、FlClash、ClashMi。从 GitHub 下载时，展开版本下的「Assets」，选择适合手机的 .apk 安装包。

    Windows 电脑

    v2rayN、Clash Verge Rev、Clash Party、FlClash。这些客户端也提供 macOS 和 Linux 版本，下载时选自己的系统。

    iPhone 或 iPad

    机场教程里常说的「小火箭」就是 Shadowrocket（美区 App Store）。如果教程推荐 ClashMi，可从 ClashMi 官网进入 App Store。

    找到订阅链接

    装好客户端后，回到机场后台，打开「我的订阅」或「一键订阅」。如果同时列出 Clash、v2rayN 等多个入口，按教程选择与你安装的客户端对应的链接或二维码。

  4. 把线路导入手机或电脑

    手机扫码

    如果机场的 iPhone 教程推荐小火箭（Shadowrocket），而你还没安装，可以先看《如何购买苹果美区id和小火箭》，装好后再回来扫码。

    在电脑或另一台设备上显示机场提供的二维码，再打开手机上的客户端，用客户端内的扫码功能导入。如果二维码就在同一部手机上，可使用客户端支持的相册识别，或按机场指南复制链接导入。

    电脑粘贴订阅链接

    在机场后台点「复制订阅链接」，打开电脑客户端，找到「订阅」或「配置」里的链接导入入口。粘贴链接，保存并更新订阅，看到节点列表就表示导入成功。

  5. 选一个节点，连接并测试

    在客户端里选一个所需地区的节点，打开连接。手机首次连接时，按系统提示允许添加 VPN 配置；电脑按机场指南启用系统代理或相应连接模式。随后用浏览器打开你要访问的网站，确认能正常加载。

    如果节点列表为空，先检查套餐是否生效、订阅格式是否选对，再更新一次订阅。如果能看到节点却连不上，先换一个节点重试。

订阅链接和二维码可能包含你的线路凭证。请只在自己的客户端中使用，发截图时记得遮住。
